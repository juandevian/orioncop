# orioncop

Modulo principal de operacion de la plataforma Panorama Legacy en VB.NET.

## Alcance
- Operacion principal de negocio.
- Integraciones con componentes comunes y reporteria.

## Estructura base
- `src/`: carpeta reservada para estabilizacion gradual de codigo.
- `docs/`: documentacion tecnica y operativa.
- `build/`: scripts y salidas de build no versionadas.

## Convencion documental
- El contenido estratgico y operativo canonico vive en `docs/`.
- Los documentos principales deben tener una unica version activa por tema.
- Se evita la duplicacion en archivos tipo `*V1.md`, `*1.md` o copias paralelas que repitan la misma informacion.
- Cuando exista un documento de referencia historica, debe mantenerse como respaldo claro y no como fuente activa.
