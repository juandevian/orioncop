# orioncop

Modulo principal de operacion de la plataforma Panorama Legacy en VB.NET.

## Alcance
- Operacion principal de negocio.
- Integraciones con componentes comunes y reporteria.

## Estructura base
- `src/`: carpeta reservada para estabilizacion gradual de codigo.
- `docs/`: documentacion tecnica y operativa.
- `build/`: scripts y salidas de build no versionadas.
