## Actualización de la línea base operativa

Con esta versión se deja alineada la base operativa de OrionCop con la versión `17.39.454.1455` y se corrigen ajustes necesarios para mantener la operación estable y consistente.

## Cambios relevantes

- Se ajustó el cálculo de pagos en `ClsItemFactura` para incluir retenciones y reversos de retenciones.
- Se ajustó la validación en `ClsCentroUtilidadOriCop` para exigir la cuenta `IDCtaImpAsumidos` cuando aplica autorización de e-factura.
- Se corrigió la carga de `txtValorDctoNuevo` en `winNotasCr`, dejando la UI consistente con el valor del ítem.
- Se actualizó la línea base operativa del ejecutable principal y la versión de librería lógica asociada.

## Impacto en la operación

Estos ajustes impactan la confiabilidad del cálculo de pagos, la validación de configuración para e-factura y la consistencia de datos mostrados en la interfaz de notas crédito, contribuyendo a una operación más segura y estable.

## Nota

Esta entrega prioriza la estabilidad operativa y la continuidad del proceso, manteniendo la base del sistema alineada con ajustes funcionales y técnicos requeridos para producción.
