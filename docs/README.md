# Documentación de orioncop

Esta carpeta contiene la documentación canónica del repositorio.

## Regla de autoridad

- Los documentos principales para gobierno y estrategia del repositorio son:
  - `PLAN_MAESTRO.md`
  - `ESTRATEGIA_REPOSITORIOS_GITHUB.md`
  - `REGLAS_NEGOCIO.md`
  - `CHANGELOG.md`
- Cualquier actualización de contenido operativo, estratégico o de versión debe hacerse primero en esta carpeta.
- Los archivos duplicados con sufijos como `*_V1.md` o `1.md` deben evitarse, salvo que exista una necesidad explícita de historial o respaldo.

## Objetivo

Mantener un conjunto documental claro, mínimo y trazable para facilitar la operación, la estrategia multi-repo y la evolución del módulo principal de OrionCop.
